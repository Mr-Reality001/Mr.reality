MR.REALITY FOOTBALL WEBSITE

Files:
- index.html = Home page
- news.html = News page
- transfers.html = Transfers page
- contact.html = Contact page
- style.css = Website design

To preview:
Open index.html in a browser.

To publish:
Upload all five files to a static website host such as GitHub Pages, Netlify, or another hosting service. Keep all files in the same folder.

The contact form is a front-end demo. It needs an email/form service to actually receive messages.
